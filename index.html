Cómo se implementará en Squarespace

🗂️ Sección Variedades

Usar Summary Block con filtro por categoría (tag). Cada categoría se crea como tag en las páginas de producto. El Summary Block muestra las tarjetas filtradas con imagen y título automáticamente.

📄 Páginas de Producto

Cada variedad como página individual dentro de una colección Blog o Products (sin carrito). Incluye Image Block, texto, y specs como Text Block formateado.

📧 Formulario de Contacto

Form Block nativo de Squarespace. Configuración: Storage → Email apuntando a agrikccr@gmail.com. Campos: Nombre, Apellido, Email, Mensaje.

📱 Diseño Responsivo

Squarespace maneja responsive automáticamente. Se ajustan paddings, fuentes y espaciado en el editor mobile. Sin código custom necesario.

🎨 Paleta de Colores

Verde #1a6b2f, acento #4caf70, textos #2c2c2c. Configurado en Design → Site Styles de Squarespace.

🔗 Navegación

Menú con 4 enlaces: Inicio, Productos, Acerca de, Contacto. El menú mobile se genera como hamburger automáticamente en Squarespace.
